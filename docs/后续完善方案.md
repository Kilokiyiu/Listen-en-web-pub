## 1. 总目标

| 优先级 | 指标 | 含义 |
|--------|------|------|
| 一级 | 网站听 / 读回访与内容消费 | 有人反复来听真题、读每日一篇 |
| 二级 | 摘词 → 至少完成一轮复习 | 检验词本 / EaseWord 是否给网站加分 |

**不做（近端冻结）：** 系统推送、多词本大改、App 独立获客、小程序重做、正式收款会员。

---

## 2. 分期路线

### 第 0 期｜观察（2～4 周）

- 看管理后台：听力完成、文章阅读、加词、进入复习、完成复习（今日 + 近 7 日）。
- 看学习记录是否出现真实条目。
- **门槛：** 各段事件持续非空，再加大功能投入。
- **动作：** 只修断点，不加会员 / 推送 / 新内容线。

### 第 1 期｜主路径打顺（约 4～6 周）— 当前工程重点

**P0**

1. 听读完成体验：完成态、从学习记录回听 / 回读。
2. 摘词路径：加词成功后强引导「去复习」。
3. 复习首轮：空词本 / 无到期词时的引导；完成一轮后正向反馈。
4. 核对埋点与 `Study` 记录一致性（听完应同时有事件 + 进度）。

**P1（有余力）**

- 首页 APK 入口降权，突出听 / 读。
- 对外品牌名统一（WordEase / EaseWord 定一个）。
- 学习记录筛选与展示加深。

### 第 2 期｜粘性（回访已稳后再做）

- 登录态「今日已听 / 已读 / 已复习」弱目标（非系统推送）。
- 每日一篇更新节奏；备考季真题可见度。
- 听力答题闭环仅在回访稳定后考虑。
- App：同步与崩溃修复 + 继续观察漏斗。

### 第 3 期｜变现准备（指标稳了再开）

- 定稿免费 / 会员边界（见下节摘要）。
- 「即将开通」意向点击（不收款）→ 再上 `plan` + 配额 + 支付。

**开做付费的门槛（建议同时满足）：**

- 连续 4～8 周听读回访可描述；
- 加词与完成复习持续发生；
- 具备基本客服 / 退款承受力。

## 3. 会员边界摘要（未实施，仅规格）

| 能力 | 免费 | 会员方向 |
|------|------|----------|
| 查词 / 列表浏览 | 不限 | 同左 |
| 云词本加词 | 累计约 50～100 | 不限 |
| 每日复习张数 | 约 20 张 / 日 | 不限 |
| 听力 | 每类（CET4/6）2～3 套可练 | 全套 + PDF/答案 |
| 每日一篇 | 近 7 天 | 全部历史 |
| 学习记录 | 近 7 天明细 | 全部历史 |

原则：永远不锁注册、查词本身、基础完成记录写入。
