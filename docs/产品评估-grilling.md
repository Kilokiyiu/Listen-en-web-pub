# ListenEase / WordEase 产品评估

> 来源：`/grill-me` 决策访谈（2026-08-04）  
> 状态：共享理解已确认；本文为评估结论，非实施清单强制排期。

---

## 1. 总判

项目作为 **ListenEase 听力站 + WordEase 配套复习端** 是成立的：内容、账号、词本、部署都在同一条生产链上。

当前最大风险不是「做不出来」，而是 **主次曾漂移**——近期工程手感大量落在 WordEase，而战略裁定是 **网站才是主产品**。评估与排期必须对齐该裁定。

**一句话结论：**  
ListenEase 作为主产品值得继续押；WordEase 值得当配套养，但不值得在证明「网站回访 + 摘词路径」之前继续加功能。

---

## 2. 已确认的产品决策

| 主题 | 结论 |
|------|------|
| 主产品 | **ListenEase 网站**（听力 / 阅读） |
| WordEase | 网站起来之后做的 **配套复习客户端**，不追求独立增长 |
| 品牌 | 听力站 **ListenEase**；软件 **WordEase** |
| 近端用户 | 先服务 **四六级**，再扩展到持续学习者 |
| 获客 → 留存 | 网页听力 / 阅读 **摘词入云端词本**；App 与网页均可复习 |
| 网页复习 | **保留完整复习**（与 App 对等能力，不强制 App 独占） |
| App 独特价值 | **碎片时间 / 提醒场景** + **离线复习**（对外近端主打前者） |
| 近端提醒形态 | **应用内到期 / 每日目标**；系统推送后置（且近端冻结） |
| 数据模型目标 | 收成 **一套真相 + 离线缓存**；现存本地 / 云「两套模式」为历史包袱，逐步弱化 |
| 离线能力 | 离线可复习并写回进度；加词偏联网 |
| 多词本 | **进阶能力**；默认单本跑通主路径即可 |
| 一级指标 | 网站 **听 / 读回访与内容消费** |
| 二级指标 | 摘词 → 至少完成一轮复习（检验配套是否加分） |
| 变现 | **先验证闭环，暂不考虑**；漏斗可测且稳定后再讨论 |
| 近 90 天必做 | 见第 4 节 |
| WordEase 冻结 | 见第 4 节 |

### 访谈中曾推翻的判断

- 「近 6–12 个月主押 App」→ 改判为 **网站主产品**
- 「本地 = 私密词本」→ 在保留双向同步后不再成立；真实需求是 **随时可学 / 离线可复习**
- 偏 App 的旧三件套（应用内提醒、离线收敛大改、App 漏斗优先）→ **降级**，让位于网站一级指标

---

## 3. 现状评估

### 3.1 对齐得好的地方

- **主价值链清晰**：真题 / BBC 等内容 → 摘词 → 词本 → 复习；网站与 App 共用 Identity + WordService。
- **配套角色可落地**：网页保留完整复习、App 做随身 / 离线，不强制「App 独占复习」。
- **技术底座够用**：分服务 + JWT + 线上域名 / APK 通道，不是空壳 MVP。
- **范围已收束**：变现后置、多词本降为进阶、推送与独立获客冻结，避免套件式膨胀。

### 3.2 主要缺口（按已定指标）

1. **一级指标测不到**  
   「听 / 读回访」若不能稳定量化，主产品好坏只能靠感觉——评估中的最大红灯。

2. **二级漏斗也未埋**  
   摘词 → 首轮复习测不准，就无法判断 WordEase 是否真的在给网站加分。

3. **产品叙事与实现曾错位**  
   本地 / 云双模式、双向同步、「私密」话术、App 主押倾向，与「一套真相 + 网站主」不一致；代码负债在 WordEase 侧更明显。

4. **品牌与命名债**  
   ListenEase / WordEase / 历史叫法混用；网页单词区归属未完全产品化，短链路话术容易糊。

5. **工程精力信号**  
   近期未提交改动偏 App（反馈、多词本、更新等），与近 90 天必做（网站回访、摘词路径、App 埋点）不完全同向——**方向已校正，手还停在旧战场**。

### 3.3 健康度（相对目标）

| 维度 | 判断 |
|------|------|
| 战略清晰度 | **高**（主次、指标、冻结清单已钉死） |
| 与代码 / WIP 一致性 | **中低**（近期手感偏配套端） |
| 主指标可验证性 | **低**（90 天第一优先是补测） |
| 配套端价值 | **有潜力，未证明**（缺二级漏斗） |
| 近端执行风险 | **范围回流**（提醒 / 离线 / 多词本再爬回必做） |

---

## 4. 近 90 天执行边界

### 4.1 唯一必做包（折中）

1. **网站听 / 读回访可测**（一级指标前提）
2. **网页摘词 → 词本路径顺滑**（接通获客 → 词本）
3. **App 最小漏斗埋点**（二级指标前提：加词来源、进入复习、完成首轮）

### 4.2 WordEase 冻结清单

**冻结：**

- 系统推送
- 多词本大改
- 独立获客 / 独立品牌投放

**可做：**

- 崩溃修复
- 同步别坏
- 漏斗埋点

**移出「唯一必做」、有余力再做：**

- 应用内复习提醒打磨
- 离线进度写回与双模式心智弱化的完整收敛
- 反馈页等周边能力

---

## 5. 建议的下一步

1. 先落地 **网站回访可测** 与 **摘词→复习最小漏斗**，再谈优化与新功能。
2. 新需求默认用本表检查：是否服务一级指标，是否突破 WordEase 冻结清单。
3. 待一级 / 二级指标可看清后，再复查：WordEase 配套是否加分、是否值得加回提醒 / 离线收敛等项。
