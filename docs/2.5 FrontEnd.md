# Front End — 前端

[← 返回项目说明](1.1%20项目说明.md)

## 1. 概述

本仓库包含 **4 个独立的前端项目**：

| 项目 | 目录 | 构建工具 | 用途 |
|------|------|----------|------|
| **en-listen-user-ui** | `Front end/en-listen-user-ui/` | Vue CLI 5 | 面向普通用户的英语学习平台 Web 端 |
| **en-listen-admin-ui** | `Front end/en-listen-admin-ui/` | Vite 5 | 面向管理员的后台管理面板 Web 端 |
| **listen-miniapp** | `Front end/listen-miniapp/` | 微信开发者工具 | 微信小程序 |
| **wordbook-app** | `Front end/wordbook-app/` | Vite + Capacitor | EaseWord Android App（配套复习） |

主 Web 端技术栈：**Vue 3 + Element Plus + Vue Router + Axios**，均部署时编译为静态文件，由 Nginx 直接托管。

## 2. 用户端（en-listen-user-ui）

### 2.1 页面结构

| 路由 | 页面名称 | 说明 |
|------|----------|------|
| `/` | HomeView | 首页，平台入口 |
| `/exams` | PaperListView | 听力真题分类与试卷列表 |
| `/exam` | QuestionView | 听力答题页，播放音频 + 显示字幕 |
| `/daily` | DailyArticleView | 每日一篇双语短文（外刊阅读） |
| `/bbc-news` | BBCNewsView | BBC 新闻实时阅读 |
| `/word-roots` | WordRootsView | 词根学习列表页 |
| `/word-roots/:id` | WordRootDetailView | 词根详情（含示例词 + 测验） |
| `/my-words` | MyWordsView | 个人单词本管理 |
| `/word-review` | WordReviewView | SM-2 单词复习页 |
| `/login` | LoginView | 登录 / 注册 |
| `/profile` | UserProfileView | 用户个人信息 |
| `/history` | StudyRecordView | 阅读历史记录 |
| `/feedback` | FeedbackView | 用户反馈（提交到 Identity Service） |

### 2.2 鉴权机制

- 需要登录的路由：`/profile`、`/history`、`/my-words`、`/word-review`
- 鉴权判断：检查 `localStorage` 中的 `token` 和 `userId`
- 未登录访问受保护路由 → 重定向至 `/login`

### 2.3 API 层

| 文件 | 说明 |
|------|------|
| `api/Request.js` | Axios 实例封装（baseURL、token 注入、错误拦截） |
| `api/Auth.js` | 登录注册接口 |
| `api/Listen.js` | 听力训练接口 |
| `api/DailyArticle.js` | 每日文章接口 |
| `api/Word.js` | 词汇学习接口（词根 + 单词本） |
| `api/Feedback.js` | 用户反馈接口 |
| `api/Study.js` | 学习记录接口 |
| `api/Analytics.js` | 用户行为埋点接口 |

### 2.4 SEO

- 通过 `utils/seo.js` 动态修改页面 `<title>` 和 `<meta description>`
- 路由 `afterEach` 钩子自动更新标题与描述
- 含 `robots.txt`、`sitemap.xml` 等标准 SEO 文件

### 2.5 特有功能

- **划词查词**：`WordSearchFloat.vue` 组件，用户选中文本后弹出浮动窗口查询单词
- **试题查看**：QuestionView 支持音频播放 + 可点击同步字幕跳转
- **词根测验**：WordRootDetailView 中内嵌选择题即时巩固
- **PDF 在线预览**：`PdfViewer.vue` 组件，使用 PDF.js 渲染试卷与答案
- **APK 下载入口**：`public/downloads/version.json` + 静态 APK 文件，支持应用内更新检查

## 3. 管理端（en-listen-admin-ui）

### 3.1 页面结构

| 路由 | 页面名称 | 说明 |
|------|----------|------|
| `/login` | LoginView | 管理员登录 |
| `/` | UploadView | 听力音频上传（自动创建分类/试卷/题目） |
| `/dashboard` | DashboardView | 数据看板（DAU、内容消费、漏斗指标） |
| `/manage` | EpisodeManageView | 题目管理（增删改查、字幕编辑、发布/隐藏） |
| `/article` | ArticleManageView | 每日文章管理（批量录入、发布/下架） |
| `/users` | UserManageView | 用户管理（启用/禁用、重置密码） |

### 3.2 鉴权机制

- 所有非登录页均需管理员 token（`localStorage` 中 `admin_token`）
- 使用 Vite 构建，较用户端的 Vue CLI 更轻量、构建更快

### 3.3 API 层

| 文件 | 说明 |
|------|------|
| `api/Request.js` | Axios 实例封装，自动携带 `admin_token` |
| `api/Admin.js` | 管理员接口（登录、上传、管理） |

## 4. 微信小程序（listen-miniapp）

- **平台**：微信小程序（原生框架）
- **账号**：与 Web 端账号互通
- **核心功能**：听力真题浏览、单词本查看（精简版）

### 项目结构

```
Front end/listen-miniapp/
├── app.js / app.json / app.wxss
├── pages/index/      # 入口页面
├── project.config.json  # ⚠️ AppID 占位为 wx0000000000000000，发布前替换
└── project.private.config.json  # 本地私有配置（已 .gitignore）
```

### AppID 替换

发布前需要将 `project.config.json` 中的 `appid` 替换为自己的微信小程序 AppID。

## 6. 部署方式

所有前端均为纯静态 SPA 或原生应用，构建后由 Nginx 或对应平台托管：

```
Front end/
├── en-listen-user-ui/   ──build──▶ Nginx / (用户端 Web)
├── en-listen-admin-ui/  ──build──▶ Nginx /admin/ (管理端 Web)
├── listen-miniapp/      ──upload──▶ 微信开发者工具（提交审核）
└── wordbook-app/        ──build:apk──▶ Capacitor → APK
```

Nginx 配置中 `/api/` 请求反向代理至后端微服务网关，静态资源请求直接返回构建产物。
