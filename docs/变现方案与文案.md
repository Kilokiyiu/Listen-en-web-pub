# ListenEase 变现方案与文案

> 更新日期：2026-09-27

> 原则：**先卖服务验证付费意愿，再开会员锁功能**；正式收款会员仍以后续方案中的指标门槛为准。

## 1. 总方案

### 1.1 三条产品线

| 产品 | 价格 | 作用 | 何时推 |
|------|------|------|--------|
| 试用站 | 免费 | 获客、建立信任 | 一直开 |
| 高频词 / 方法资料包 | ¥9.9 | 低门槛成交、测需求 | 本周可上 |
| 四六级精听陪练营 | ¥199 / 7 天 | 主现金流 | 本周可上 |
| 会员（后置） | ¥68/季 或 ¥128/年 | 规模化收入 | 回访稳定后再开 |

### 1.2 用户路径

```
短视频 / 闲鱼 → 免费试用网站 → 9.9 资料包 或 直接 199 陪练 →（后期）转会员
```

### 1.3 本周执行清单

1. **今天**：把 199 详情文案贴到闲鱼 + 朋友圈；准备好开营须知。
2. **明天**：发 1 条小红书 / 短视频（带网站演示）。
3. **有人询价**：先发 D1 任务样例，再收款。
4. **首期只收 5 人**：把 SOP 跑顺，再扩到 10 人。
5. **会员**：继续用「即将开通，预约名额」收集意向，暂不收款。

## 2. 免费 vs 会员（边界 + 文案）

### 2.1 功能边界（定稿建议）

| 能力 | 免费 | 会员 |
|------|------|------|
| 注册 / 查词 / 基础学习记录 | ✓ | ✓ |
| 听力真题 | 每级 2～3 套 | 全套 + 答案 / PDF |
| 每日一篇 | 近 7 天 | 全部历史 |
| 云词本加词 | 累计 80 词 | 不限 |
| 每日复习 | 20 张 / 日 | 不限 |
| 学习记录明细 | 近 7 天 | 全部 |

原则：永远不锁注册、查词本身、基础完成记录写入。会员只解锁「备考深度与用量」。

### 2.2 网站会员意向页文案

**标题**

ListenEase 会员：听完全部真题，词本不再限额

**副标题**

免费就能开始精听；会员解锁完整题库与无限复习，专为四六级冲刺设计。

**权益三条**

1. 四六级听力全套可练，含答案与原文对照  
2. 云词本加词不限量，复习张数不限  
3. 每日一篇与学习记录完整回溯，备考不中断  

**按钮**

- 主按钮：`即将开通，预约名额`
- 次按钮：`先免费体验精听`

**底部信任句**

查词、注册、基础练习永久免费。会员只解锁「备考深度」，不绑架入门。

### 2.3 开做正式付费的门槛（与后续方案一致）

建议同时满足后再上 `plan` + 配额 + 支付：

- 连续 4～8 周听读回访可描述；
- 加词与完成复习持续发生；
- 具备基本客服 / 退款承受力。

## 4. ¥199 交付 SOP

### 4.1 报名当天（D0，约 15 分钟）

1. 拉微信，确认：四级 / 六级、考试月份、目前大概正确率。  
2. 发网站链接 + 注册指引。  
3. 发《开营须知》。  
4. 建打卡表字段：日期 / 完成套题 / 摘词数 / 今日复习张数 / 最大困难（一句话）。

#### 开营须知（可直接复制）

```
欢迎加入 ListenEase 7天精听陪练营

每天任务（约40–60分钟）：
1. 精听指定套题（网站完成）
2. 不会的词点选进词本
3. 完成到期复习（有则必做）
4. 群里打卡：截图 + 一句话复盘

我的承诺：
- 每天24点前反馈你的打卡
- 指出1个最大问题 + 明天怎么改

请回复：四级/六级 + 考试月份
```

### 4.2 每日节奏（运营侧）

| 时间 | 动作 |
|------|------|
| 早 9:00 前 | 发当日任务（哪一套、听几遍、摘词目标） |
| 全天 | 学员打卡 |
| 晚 24:00 前 | 逐人回复：肯定一点 + 纠一个问题 + 明日聚焦 |

#### 每日任务模板

```
【D{n} 任务｜{四级/六级}】
1. 打开 ListenEase，完成：{专辑/套题名}
2. 第1遍：只听选题，不看原文
3. 第2遍：对原文，生词全部点进词本（目标≥15词）
4. 完成今日到期复习
5. 打卡格式：
   - 完成截图
   - 今天错因（语音/注意力/词汇/题型）选一个
   - 明天只改这一件事：______
```

### 4.3 七天内容排期

| 天 | 主题 | 你要盯的点 |
|----|------|------------|
| D1 | 建立闭环：1 套精听 + 首次摘词 | 会不会用网站摘词 |
| D2 | 听前读题习惯 | 是否盲目开听 |
| D3 | 连读 / 弱读导致的「听不清」 | 是词汇问题还是语音 |
| D4 | 长对话信息定位 | 会不会抓信号词 |
| D5 | 短文 / 新闻类节奏 | 笔记是否过重 |
| D6 | 错题回听（只重听错段） | 有没有逃避难点 |
| D7 | 复盘 + 薄弱词本整理 + 考后自学计划 | 给出续学路径 |

> 套题名请替换为站内真实专辑 / 真题名称（四级、六级分轨各准备一版）。

### 4.4 结营（D7）

#### 结营小结模板

```
【你的7天结营小结】
完成套题：x/7
累计摘词：约 xx
已复习轮次：xx
最大进步：……
仍需突破：……
建议接下来2周：
1. 每周精听 3 套
2. 词本每日清到期
3. （可选）续1周答疑 / 转会员（上线后）
```

#### 轻续费（可选）

- 产品：`¥99 加 1 周答疑`（只复盘，不再高强度带任务）
