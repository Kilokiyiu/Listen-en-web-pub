# ListenService — 听力训练服务

[← 返回项目说明](1.1%20项目说明.md)

## 1. 职责

管理听力训练的全部数据，包括分类（Category）、试卷（Album）和题目（Episode）的增删改查，并提供音频文件上传与字幕管理功能。普通用户只读，管理员可写。

## 2. 项目结构

```
ListenService/
├── ListenService.Domain/            # 领域层
│   ├── Entity/
│   │   ├── Category.cs              # 分类聚合根（CET4 / CET6 等）
│   │   ├── Album.cs                 # 试卷聚合根
│   │   └── Episode.cs               # 题目聚合根
│   └── IListenRepo.cs               # 仓储接口
├── ListenService.Infrastrucure/     # 基础设施层
│   ├── ListenDbContext.cs           # EF Core DbContext
│   ├── ListenRepo.cs                # 仓储实现
│   ├── InitService.cs               # 数据初始化
│   └── EntityConfig/                # EF Core 实体配置
└── ListenService.WebAPI/            # 表现层
    ├── Controllers/

    │   └── Admin/AdminController.cs     # 管理端写入 API

    └── Program.cs
```

## 3. 领域模型

数据结构为三层聚合：**Category → Album → Episode**

```
Category（分类）
└── Album（试卷）
    └── Episode（题目）
```

### Category（分类）

用于将内容按考试类型归类，如 CET-4、CET-6。

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | `Guid` | 唯一标识 |
| `Name` | `MultilingualString` | 双语名称（中文 + 英文） |
| `Code` | `string` | 编码（如 `cet4`），全小写 |
| `SequenceNumber` | `int` | 排序权重 |
| `CoverUrl` | `string?` | 封面图片路径 |

### Album（试卷）

对应一套完整的听力试卷，如「2024年6月大学英语四级听力真题（第1套）」。

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | `Guid` | 唯一标识 |
| `Name` | `MultilingualString` | 双语名称 |
| `CategoryId` | `Guid` | 所属分类 |
| `SequenceNumber` | `int` | 排序权重 |
| `IsVisible` | `bool` | 是否对用户可见 |

### Episode（题目）

试卷中的单个听力段落，包含音频和同步字幕。

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | `Guid` | 唯一标识 |
| `Name` | `MultilingualString` | 题目名称，如「Section A」 |
| `AlbumId` | `Guid` | 所属试卷 |
| `AudioUrl` | `string` | 音频文件相对路径 |
| `DurationInSecond` | `double` | 音频时长（秒），由服务器存储 |
| `Subtitle` | `string` | 字幕内容（JSON 格式） |
| `SubtitleType` | `string` | 字幕格式，当前固定为 `json` |
| `IsVisible` | `bool` | 是否对用户可见 |

#### 字幕 JSON 格式

```json
[
  { "start": 0, "end": 3.5, "text": "原文内容", "translation": "中文译文" },
  { "start": 3.5, "end": 8.0, "text": "...", "translation": "..." }
]
```

## 4. API 接口

### 用户端（无需鉴权）

路由前缀：`/Listen`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/GetCategories` | 获取所有分类 |
| `GET` | `/GetAlbumsByCategoryId?categoryId=` | 获取某分类下的所有试卷 |
| `GET` | `/GetEpisodesByAlbumId?albumId=` | 获取某试卷的所有题目 |
| `GET` | `/GetDetailEpisodesByEpisodeId?episodeId=` | 获取某题目的详细信息（含字幕） |

### 管理端（需要 `Admin` 角色）

路由前缀：`/Admin`

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/UploadAudio` | 上传音频，自动创建 Category / Album / Episode |
| `POST` | `/UpdateEpisodeSubtitle` | 更新题目字幕 |
| `GET` | `/GetAllEpisodes` | 获取所有题目（管理列表） |
| `GET` | `/GetAllAlbums` | 获取所有试卷（管理列表） |
| `POST` | `/ToggleEpisodeVisibility` | 切换题目显示/隐藏 |
| `POST` | `/ToggleAlbumVisibility` | 切换试卷显示/隐藏 |
| `POST` | `/DeleteEpisode` | 删除题目（同时删除音频文件） |

## 5. 音频上传说明

`UploadAudio` 接口会自动完成以下操作：

1. 检查 Category 是否存在，不存在则自动创建
2. 根据年份 + 月份 + 套数生成标准化 Album 名称
3. 将音频文件保存至 `wwwroot/audios/{CATEGORY}/{year}/{year}.{month}.{setNumber}.mp3`
4. 创建 Episode 记录，`AudioUrl` 指向上传的文件

> 音频文件由 ListenService 自身管理，不依赖 FileService。
