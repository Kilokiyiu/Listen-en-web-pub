# 项目介绍

## 1. 概述

ListenEase 是一个专注于英语听力学习的开源平台，融合**听力考试训练**、**每日外刊阅读**和**词根学习**三大模块，帮助学习者在碎片化时间内高效提升英语能力。

## 2. 技术架构

本项目基于 **DDD（领域驱动设计）** 思想开发，采用前后端分离模式，旨在提高项目在开发过程中的合理性与管理上的高效性。

- **前端**: [Vue 3](https://cn.vuejs.org/) + Element Plus，分为用户端和管理端两个独立项目
- **后端**: [ASP.NET Core 10](https://learn.microsoft.com/en-us/aspnet/core/?view=aspnetcore-10.0) 微服务架构，每个业务模块独立部署

## 3. 部署方式

项目采用 **Docker Compose** 一键部署，整套环境包含：

```
┌─────────────────────────────────────────────┐
│                  互联网                       │
│              https://你的域名                  │
└──────────────────┬──────────────────────────┘
                   │
          ┌────────▼────────┐
          │  Nginx (443)    │  ← TLS 1.3 证书（Let's Encrypt 自动续期）
          │  gzip + HTTP/2  │
          └───┬───┬───┬───┬─┘
              │   │   │   │
     ┌────────▼───▼───▼───▼────────┐
     │       Docker Compose        │
     │                             │
     │  IdentityService :5000      │
     │  ListenService   :5001      │
     │  ArticleService  :5002      │
     │  WordService     :5003      │
     │  FileService     :5004      │
     │  SQL Server 2022 :1433      │
     │                             │
     │  前端静态文件由 Nginx 直出    │
     └─────────────────────────────┘
```
