# KaoyanService — 考研英语服务

[← 返回项目说明](1.1%20项目说明.md)

## 1. 职责

提供考研英语试卷（完形填空、阅读理解等）的发布、浏览与在线作答；支持整卷 PDF 上传与下载。与听力服务独立，数据存在单独数据库。

## 2. 结构

```
KaoyanService/
├── KaoyanService.Domain/
│   └── Entity/ExamPaper.cs          # 含 DocumentUrl 等试卷文档字段
├── KaoyanService.Infrastructure/
│   └── Migrations/...AddExamPaperDocumentUrls.cs
└── KaoyanService.WebAPI/
    ├── wwwroot/                     # 上传的试卷文档静态目录（勿提交真实 PDF）
    └── Controllers/
        ├── KaoyanController.cs   # 用户端：试卷列表 / 详情 / 提交
        └── AdminController.cs    # 管理端：导入、编辑、显隐、PDF 上传
```

## 3. 用户端接口

路由前缀：`/api/kaoyan`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/Kaoyan/GetPapers` | 试卷列表（可按系列筛选；含文档 URL） |
| `GET` | `/Kaoyan/GetPaperDetail` | 试卷题目与选项 |
| `POST` | `/Kaoyan/SubmitAnswers` | 提交作答（可整卷统一对答案） |
| `POST` | `/Kaoyan/CheckAnswer` | 单题校验 |

管理端对应 `/api/kaoyan/Admin/*`（导入 JSON、保存内容、切换可见性、上传试卷 PDF）。

导入工具见 `tools/kaoyan-paper-pdf-import/`、`tools/kaoyan-reading-import/`、`tools/kaoyan-cloze-import/`。

## 4. 部署

`deploy/docker-compose.yml` 中的 `kaoyan-service`，Nginx 将 `/api/kaoyan/` 反代到该容器。
