# KaoyanService — 考研英语服务

[← 返回项目说明](1.1%20项目说明.md)

## 1. 职责

提供考研英语试卷（完形填空、阅读理解等）的发布、浏览与在线作答。与听力服务独立，数据存在单独数据库。

## 2. 结构

```
KaoyanService/
├── KaoyanService.Domain/
├── KaoyanService.Infrastructure/
└── KaoyanService.WebAPI/
    └── Controllers/
        ├── KaoyanController.cs   # 用户端：试卷列表 / 详情 / 提交
        └── AdminController.cs    # 管理端：导入、编辑、显隐
```

## 3. 用户端接口

路由前缀：`/api/kaoyan`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/Kaoyan/GetPapers` | 试卷列表（可按系列筛选） |
| `GET` | `/Kaoyan/GetPaperDetail` | 试卷题目与选项 |
| `POST` | `/Kaoyan/SubmitAnswers` | 提交作答 |
| `POST` | `/Kaoyan/CheckAnswer` | 单题校验 |

管理端对应 `/api/kaoyan/Admin/*`（导入 JSON、保存内容、切换可见性）。

## 4. 部署

`deploy/docker-compose.yml` 中的 `kaoyan-service`，Nginx 将 `/api/kaoyan/` 反代到该容器。
