# 四六级听力功能解读

> 目标：让你能对照代码读懂「听一套 CET 真题」整条链路，方便自己调优。  
> 主战场前端：`Front end/en-listen-user-ui`  
> 主战场后端：`ListenService`  
> 相关体验文档：`docs/项目说明-体验向代码Review.md`、`docs/听力内容残缺清单.md`

---

## 1. 一句话模型

```
分类 Category（CET4 / CET6）
  └─ 试卷 Album（例如「2024年6月第一套」）
       ├─ Episode（整卷音频 + 整卷字幕/原文）      ← 偏「听」
       ├─ QuizSection（Section A/B/C 下的各段材料） ← 偏「做题」
       │    └─ QuizQuestion（单选题，选项 JSON）
       └─ PaperFileUrl / AnswerFileUrl（试卷/答案 PDF）
```

用户路径：

```
入口页选四级/六级 → 试卷列表 → /exam?albumId=xxx
  → 播整卷（或分段）音频
  → 在线单选（模拟 / 练习）
  → 交卷看答案 / 看原文 / 下 PDF
  → 「完成本卷」→ Identity 学习记录 + 埋点
```

## 2. 用户从哪里进来（多个入口，同一练习页）

| 入口 | 路由 | 页面 | 说明 |
|------|------|------|------|
| 手机底栏「听力」 | `/exams` | `PaperListView.vue` | 先选分类再列表 |
| SEO / 栏目 | `/cet4` `/cet6` `/si-liu-ji` `/listening` | `CategoryHubView.vue` | 落地页 → 进列表或练习 |
| 首页分类 Tab | `/` → 跳转 | `HomeView.vue` | 用 `categoryMeta` 展示 CET4/6 |
| 学习记录回听 | `/history` | `StudyRecordView.vue` | 再进 `/exam?albumId=` |

**真正练习页只有一个：**

- 路由：`/exam?albumId=<Guid>`
- 组件：`src/views/QuestionView.vue`（核心，建议精读）

桌面顶栏没有单独「听力」项，CET 多从首页或 SEO hub 进；手机底栏更直接。调 IA 时要两边一起想。

## 3. 数据模型（ListenService.Domain）

### 3.1 Category（分类）

文件：`ListenService.Domain/Entity/Category.cs`

- `Code`：如 `cet4` / `cet6`（前端 `categoryMeta.js` 靠这个展示文案）
- `Name`：多语言 `MultilingualString`（中/英）
- `SequenceNumber`、`CoverUrl`

前端展示配置：`src/utils/categoryMeta.js`（标题、祝福语、列表标签）。  
库里的分类 Id 是 Guid；列表页用 `?categoryId=<Guid>` 拉试卷。

### 3.2 Album（一套卷）

文件：`Album.cs`

| 字段 | 含义 |
|------|------|
| `CategoryId` | 属于四级还是六级 |
| `Name` | 卷名 |
| `IsVisible` | 隐藏后用户列表不可见 |
| `PaperFileUrl` | 试卷 PDF 相对路径 |
| `AnswerFileUrl` | 答案 PDF 相对路径 |

一套「卷」≈ 一次考试听力整卷，不是单题。

### 3.3 Episode（整卷听力资源）

文件：`Episode.cs`  
注释里叫「题目」，实际在产品里更接近 **整卷音频槽位**：

| 字段 | 含义 |
|------|------|
| `AudioUrl` | 整卷 mp3 相对路径，如 `/audios/CET4/...` |
| `DurationInSecond` | 时长 |
| `Subtitle` | 字幕/原文（JSON 或文本，MVP 标成 json） |
| `IsVisible` | 可单独隐藏 |

练习页通常取该 Album 下 **第一条可见 Episode** 作为整卷播放器源。  
**没有 Episode 音频 = 页面提示「暂无整卷音频」**（仍可能有分段题）。

### 3.4 QuizSection + QuizQuestion（在线做题）

- `QuizSection`：挂在 Album 下，分 `GroupName` = Section A / B / C；有本段 `Transcript`、可选 `AudioUrl`
- `QuizQuestion`：挂在 Section 下；`OptionsJson`、`CorrectAnswer`（下标）、可选 `Explanation`

判分在服务端 `SubmitQuiz`；`GetQuizByAlbumId` **不下发正确答案**。

历史演进造成的「双轨」：

| 能力 | 主要数据 |
|------|----------|
| 听整卷 + 整卷原文 | Episode |
| 分段原文 + 在线题 | QuizSection / QuizQuestion |
| PDF | Album 上的两个 URL |

内容残缺清单正是按「整卷音频 / 整卷原文 / 试卷PDF / 答案PDF / 在线题」五项扫的——五项来自两套结构，容易缺一边。

## 4. 后端 API（ListenController）

文件：`ListenService.WebAPI/Controllers/Listen/ListenController.cs`  
路由双挂：`Listen/{action}` 与 `/api/listen/Listen/{action}`（生产走后者）。

| 方法 | 作用 | 练习页是否用 |
|------|------|----------------|
| `GetCategories` | 所有分类 | 列表 / 首页 / 解析级别 |
| `GetAlbumsByCategoryId` | 某类下试卷 | 列表页 |
| `GetAlbumById` | 单卷详情 + PDF 地址 | 练习页 |
| `GetEpisodesByAlbumId` | 整卷 Episode 列表 | 练习页（取音频/字幕） |
| `GetDetailEpisodesByEpisodeId` | 单个 Episode | 较少直接用 |
| `GetQuizByAlbumId` | 分区 + 题（无答案） | 练习页 |
| `SubmitQuiz` | 交卷判分（可带 `sectionId`） | 练习页 |
| `GetAnnouncementBoard` | 公告（非听力本体） | 顶栏 |

判分逻辑要点：`Answers` 为 `{ questionId, selectedIndex }[]`；可按 `sectionId` 只判一段；返回每题对错、正确答案、解析、得分率。

Admin 上传音频、改字幕、显隐、存 Quiz 等在 `Controllers/Admin/AdminController.cs`，对应后台 `ListenContentView` / `EpisodeManageView`。

静态文件：音频/PDF 在 Listen 服务 `wwwroot`；生产 nginx 有 `/api/listen/audios/`、`/api/listen/papers/` 反代。

## 5. 前端 API 封装

文件：`src/api/Listen.js`

- 走 `Request.js` 的 `baseURL: /api/listen`
- **分类 / 试卷列表有 5 分钟 localStorage 缓存**（改后台显隐后用户可能短时仍见旧列表 → `clearCache()`）
- 存在 **mock 卷** 分支（`mockListeningQuiz.js`），本地演示用

## 6. 练习页 `QuestionView.vue`（精读地图）

打开顺序建议：模板结构 → `load`/`onMounted` → 模式与交卷 → `markComplete`。

### 6.1 页面块

1. **整卷音频卡**：`<audio :src="audioUrl">`；无则提示补传  
2. **答题设置**：模拟模式 / 练习模式；是否显示题干  
3. **Section Tab**（A/B/C）→ **材料 Tab**（News Report 1…）  
4. **OnlineQuizPanel**：单选；练习模式可分段交卷，模拟模式整卷再交  
5. **本段原文**：解锁条件与模式/是否已对答案有关  
6. **整卷原文 / PDF 下载 / 完成本卷**

### 6.2 两种做题模式

| 模式 | 行为 |
|------|------|
| `exam` 模拟 | 尽量接近考试：答完再看答案；`defer-check`；整卷交卷 |
| `practice` 练习 | 一段做完可对答案；`submitQuiz(..., sectionId)` |

模式存在本地（`loadPracticeMode`）；切换模式会提示「仍保留已看过的答案」，可一键重作。

进度键大致：`listen:quiz:{albumId}:{sectionId}`（刷新可恢复作答）。

### 6.3 加载数据（并行）

练习页大致同时请求：

- `getEpisodesByAlbumId` → 整卷 `audioUrl` + 字幕  
- `getAlbumById` → 标题、PDF  
- `getQuizByAlbumId` → sections/questions  
- 再用 categories 解析 `cet4`/`cet6` 展示

相对路径经 `toFileUrl` 拼成可播/可下的 URL。

### 6.4 「完成本卷」与埋点

`markComplete`：

1. Analytics：`listen_complete`  
2. 未登录：手动点完成 → 引导登录；若是音频播完自动触发 → 只推反馈礼包  
3. 已登录：`recordStudyActivity({ activityType: 'listen', contentId: albumId, ... })`  
4. 然后鼓励反馈（桌宠/礼包链路）

分段练习对答案时还会记 `listen_quiz` 类学习活动（见 `onSectionSubmitted` 一带）。

音频结束可通过 `useAudioPlayer` 的 `onEnded` 自动 `markComplete(true)`。

## 7. 列表页 `PaperListView.vue`

- 无 `categoryId`：展示分类卡片（CET4/6 等）  
- 有 `categoryId`：`getAlbumsByCategoryId` → 分页点选 → `goDetail(albumId)` → `/exam`  
- 分类文案来自 `listCategoryMeta` + 接口 `code`

`CategoryHubView` 类似，偏 SEO 文案与入口聚合。

## 8. 和 Identity 的交接（体验指标）

| 时机 | Analytics | Study |
|------|-----------|--------|
| 听完 / 点完成 | `listen_complete` | `activityType: 'listen'` |
| 交卷/段对答案 | `listen_quiz_submit` 等 | 常有 `listen_quiz` |
| 任意页 | `page_view` | — |

后台漏斗看的是 Identity；**只改 Listen 不改前端完成逻辑，指标不会自己变好。**

## 9. 内容运营侧（为何「能进页但没法练」）

完整一套用户侧期望：

1. 可见 Album  
2. 至少一条有 `AudioUrl` 的 Episode（整卷听）  
3. 足够 QuizSection/Question（在线答，理想约 25 题）  
4. 可选：整卷 Subtitle、试卷/答案 PDF、分段 Audio  

缺什么，练习页就降级成什么（提示无音频、无题、无 PDF）。  
清单：`docs/听力内容残缺清单.md`。补内容走 Admin + `tools/cet-listening-import`。

## 11. 调优时优先动哪里

| 目标 | 优先改 |
|------|--------|
| 入口难找 / IA | `HomeView`、`AppMobileNav`、`PaperListView`、`seoHubs` |
| 播放/锁屏/进度 | `QuestionView` + `useAudioPlayer` |
| 答题交互 | `OnlineQuizPanel`、模式逻辑 |
| 空态 / 残缺提示 | `QuestionView` 模板 + 列表是否展示缺音频卷 |
| 完成与回访 | `markComplete`、`StudyRecordView`、Identity Study |
| 真题能不能练 | **内容与 Admin**，不是再堆前端功能 |
| 列表数据「改了没刷新」 | `Listen.js` 的 5 分钟缓存 |
