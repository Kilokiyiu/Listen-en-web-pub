# ArticleService — 每日外刊服务

[← 返回项目说明](1.1%20项目说明.md)

## 1. 职责

管理「每日一文」功能，为用户提供每天定时发布的双语英文短文（BBC 外刊等）；同时集成 BBC RSS 实时抓取能力，用户可直接在平台浏览原版新闻原文。管理员可批量维护文章库，用户端支持阅读状态追踪与收藏。

## 3. 领域模型

### DailyArticle（每日文章）

平台自维护的双语短文，到达 `PublicDate` 后自动对用户可见。

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | `Guid` | 唯一标识 |
| `PublicDate` | `DateTime` | 公开日期（精确到天），到达该日期后文章可见 |
| `Title` | `MultilingualString` | 双语标题（中文 + 英文） |
| `EnglishText` | `string` | 英文正文 |
| `ChineseText` | `string` | 中文译文 |
| `ArticleUrl` | `string?` | 原文链接（可选） |
| `IsPublished` | `bool` | 是否已发布（管理员手动控制） |
| `CreationTime` | `DateTime` | 录入时间，系统自动设置 |

### UserArticleStatus（用户阅读状态）

记录用户与每篇文章的关联关系，实现已读标记和收藏功能。

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | `Guid` | 唯一标识 |
| `UserId` | `Guid` | 用户 ID |
| `ArticleId` | `Guid` | 对应文章 ID |
| `IsRead` | `bool` | 是否已读 |
| `IsFavorited` | `bool` | 是否已收藏 |
| `CreatedAt` | `DateTime` | 首次交互时间 |
| `FavoritedAt` | `DateTime?` | 收藏时间 |

## 4. API 接口

### 用户端（需要登录鉴权）

路由前缀：`/Article`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/GetArticleByDate?date=` | 获取指定日期的文章，含当前用户已读/收藏状态 |
| `POST` | `/MarkIsRead` | 将指定文章标记为已读 |
| `POST` | `/ToggleFavoriteAsync` | 切换指定文章的收藏状态 |
| `GET` | `/GetReadHistoryAsync?page=&pageSize=` | 获取用户阅读历史（分页，默认每页 20 条） |

### BBC 实时抓取（无需鉴权）

路由前缀：`/BBC`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/GetTopNews?category=` | 抓取 BBC RSS 最新头条，最多 30 条 |
| `GET` | `/GetArticleDetail?url=` | 获取指定 BBC 文章的原文全文内容 |
| `GET` | `/GetCategories` | 获取所有可用分类列表 |

BBC 支持分类：`world`（世界）、`technology`（科技）、`business`（商业）、`science`（科学环境）、`health`（健康）、`entertainment`（娱乐艺术）

### 管理端（需要管理员权限）

路由前缀：`/Admin`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/GetAllArticles` | 获取所有文章，包括未发布的 |
| `POST` | `/AddArticle` | 添加单篇文章，默认自动发布 |
| `POST` | `/BatchAddArticles` | 批量添加文章 |
| `POST` | `/UpdateArticle` | 更新文章内容 |
| `POST` | `/DeleteArticle` | 删除文章 |
| `POST` | `/TogglePublishStatus` | 切换文章发布/下架状态 |

## 5. 文章发布机制

`PublicDate` 控制文章对用户的可见时机，`IsPublished` 由管理员手动控制上下架，两者共同决定文章是否展示：

```
用户可见 = IsPublished == true AND PublicDate <= 今天
```

管理员通过后台批量录入文章，提前设置好 `PublicDate`，到日期后自动展示，无需手动操作。
