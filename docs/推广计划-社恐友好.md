> 人格约束：**少真人出镜、少私聊拉扯、少当面推销**；优先异步内容 + 标准化回复  
> 网站：https://your-domain.com/#/

## 0. 你适合 / 不适合的推广方式

### 适合（默认只做这些）

| 方式 | 社恐压力 | 说明 |
|------|----------|------|
| 小红书图文 + 录屏 | 低 | 可匿名昵称，不露脸 |
| 抖音/视频号「纯屏幕录制 + 字幕」 | 低 | 不用口播露脸，可用系统朗读或纯字幕 |
| 朋友圈偶尔发 | 低～中 | 单向广播，不强制回复每个人长聊 |
| 静默放链接（签名、个人简介、海报二维码） | 极低 | 零社交 |
| SEO / 站点本身可搜 | 极低 | 一次优化，长期吃 |

### 明确不做（至少近 30 天）

- 露脸直播、连麦答疑
- 加陌生备考群逐个私聊安利
- 教室/讲座上台分享
- 闲鱼砍价式多轮议价（本阶段也不卖货）
- 强行「每天必须回完所有私信长文」

### 社交能量预算（请当真）

- **每周对外社交上限**：累计私信回复 ≤ 30 分钟；评论区简短回复即可  
- **内容制作**：可一个人关房门做，算「工作」不算「社交」  
- 私信统一用下方「复制粘贴回复」，超过 3 句解释就停，丢链接

## 1. 目标（4 周）

结合你当前数据（总用户 ~94，日 UV 曾到 ~150 后跌到 ~20+，听力有人点、词本几乎没人用）：

| 指标 | 现在大概 | 4 周目标 | 为什么 |
|------|----------|----------|--------|
| 日均 UV | ~20–40（波动大） | 稳定 **60+** 天均 | 证明获客可持续，不只脉冲 |
| `/exam` 周 UV | ~100 | **150+** | 人要摸到核心听力 |

| 单词本用户 | 9 | **20+** | 留存抓手 |

只盯这 5 个；别同时开 5 个平台。

**主路径（本阶段唯一）：**

```
小红书/短视频（录屏） → 网站免费试用 → 听一套 → 点词进词本 → 第二天回访复习
```

## 2. 人设与账号（降低暴露焦虑）

1. **昵称**：可用「ListenEase / 精听笔记 / 四六级听力工具」等产品向，不一定用实名。  
2. **头像**：Logo、耳机剪影、波形图即可，不必真人。  
3. **简介固定一句 + 链接：**

```
做了个免费四六级精听站：听完生词点一下进词本
试用：your-domain.com
```

4. **是否露脸**：默认不露。需要「讲解」时用：屏幕录制 + 大字幕 + 可选 TTS。  
5. **评论区策略**：只置顶链接；别人问「怎么用」→ 复制模板回复，不展开人生故事。

## 3. 内容母版（做 1 次，用 1 个月）

社恐友好的关键：**周末集中拍 4 条，工作日只点「发布」**，避免每天临时社交决策。

### 3.1 唯一演示脚本（30–45 秒，纯录屏）

1. 字幕：真题听很多遍，正确率却不动？  
2. 打开 your-domain.com → 点进一套听力  
3. 对原文 → **点击生词** → 显示进词本（特写 3 秒）  
4. 字幕：免费试用，主页链接 / 评论区链接  
5. 结束卡：`your-domain.com`

导出横版 + 竖版各一，小红书/抖音通吃。

### 3.2 小红书标题库（轮换，勿带价格）

- 四六级听力不是听不懂，是听完不会复盘  
- 我把真题精听做成了「点词就进词本」  
- 备考听力：不要只刷套题，把生词留下来  
- 免费精听站自用分享（含原文点查）  
- 正确率卡住的人，多半缺「摘词→复习」

### 3.3 正文固定结构（复制改数字即可）

```
痛点：听了不少套，正确率不动。

我后来只做四步：
1. 精听一套
2. 对原文
3. 生词点进词本
4. 隔日按提醒复习

工具我做成了网站，目前免费：
https://your-domain.com/#/

适合：正在备考四六级、愿意每天 40 分钟精听的人。
```

### 3.4 评论区置顶（不卖课版）

```
网站免费试用：https://your-domain.com/#/
用法：选听力 → 听 → 点生词进词本 → 第二天复习
问题直接评论，我看到会回（可能稍慢）
```

### 3.5 私信统一回复（社恐保命模板）

对方：「链接呢 / 怎么用 / 是什么」

```
这是免费精听站：https://your-domain.com/#/
建议：先听一套真题 → 对原文时点生词进词本。
卡在某一步可以跟我说「卡在xx」，我按步骤回。
```

对方追问很细、要你长期陪练：

```
我这边目前主要维护网站，没法一对一陪练～
你可以先按站内流程自己跑一周，有产品问题再问我。
```

（本阶段不承诺陪练，保护精力与边界。）

## 4. 渠道计划（只开 2 个主渠道 + 1 个静默）

### A. 小红书（主战场，每周 3 篇）

| 日 | 动作 | 耗时 |
|----|------|------|
| 周六或周日 | 批量剪 3 条笔记（1 录屏改 3 标题/封面） | 2–3h |
| 周一 / 三 / 五 | 各发 1 篇，置顶评论 | 15min/次 |
| 每天 | 只回短评，用模板；超时就第二天回 | ≤15min |

标签示例：`#四级听力` `#六级听力` `#英语精听` `#四六级备考` `#听力技巧`

### B. 抖音或视频号（复用，每周 3 条）

- **同一条录屏**，换标题发，不额外出镜  
- 发布时间可与小红书错开半天  
- 简介同小红书；视频结尾字幕必须有域名

若只能维护一个短视频平台：**优先小红书**（四六级搜索意向更稳）。

### C. 静默位（几乎零社交）

- 微信/QQ 签名或状态：网站链接  
- 朋友圈：**每两周最多 1 条**，用产品演示图，文案用 3.3，不 @ 人、不求转发  
- 若有桌面/宿舍：打印一张 `docs/poster.html` 海报，只放二维码/域名（不用站旁边讲解）

### 明确暂缓

知乎长文、B 站长视频、公众号、投流、闲鱼卖课、进群逐个安利。

及格线：`/exam` 周 UV 比 9/28 那周有可见上升。

### 第 3 周：推动摘词（留存）

- 内容特写「点击生词」到进词本，反复讲这一个动作

- 看「7 日加词」「单词本用户」

及格线：7 日加词相关从「约 1」进入「肉眼可见的两位数趋势」。

### 第 4 周：复盘与加减法

- 保留：带来 UV 最高的 2 类标题

## 7. 能量管理（社恐专用）

1. **把「回复」当成客服班次，不是随时在线好友。** 设每天一个 15 分钟窗口。  
2. **评论区可以慢。** 置顶里写「可能稍慢」，降低道德压力。  
3. **拒绝一对一陪学。** 本阶段产品是网站自助；你不是助教。  
4. **不要为了推广去开摄像头。** 录屏足够。  
5. **若某周社交电量透支：** 只发已做好的存货，暂停回私信，保发布不断更。  
6. **朋友圈可选。** 完全不做朋友圈，计划仍然成立。

## 8. 成功 / 失败怎么判断

### 继续加码（第 5 周起可考虑）

- 日均 UV 能稳住 60+  
- `/exam` 明显变热  
- 加词与复习开始出现连续天数  

那时再加：第 4 条周更、或一篇知乎经验贴（仍可匿名）。

### 先别加渠道，先修站

- 内容发了，UV 不动 → 检查链接、域名、手机打开是否正常、是否被限流  
- UV 涨、加词仍接近 0 → 优先改产品引导，而不是更拼命发帖  
- 一发版 UV 就掉 → 收紧发布频率，先稳站点
