# WordService — 词汇学习服务

[← 返回项目说明](1.1%20项目说明.md)

## 1. 职责

提供两条并行的词汇学习路线：一是**词根学习**，通过系统化的词根-词缀体系帮助用户掌握单词构词规律；二是**个人单词本**，用户可自由添加单词并通过 SM-2 间隔重复算法安排科学复习计划。

## 2. 项目结构

```

│       └── UserProgress.cs         # 用户学习进度（词根进度 + 个人单词本）
├── WordService.Infrastructure/      # 基础设施层（拼写为 Infrastrucure）
│   ├── WordDbContext.cs             # EF Core DbContext

│   ├── InitService.cs               # 数据初始化
│   └── EntityConfig/                # EF Core 实体配置
└── WordService.WebAPI/              # 表现层
    ├── Controllers/Word/

    │   └── UserWordController.cs        # 个人单词本接口
    └── Program.cs
```

## 3. 领域模型

### 3.1 词根体系

#### WordRoot（词根）

系统预置的词根数据，来自 word-root-workshop 数据集。

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | `Guid` | 唯一标识 |
| `RootId` | `int` | 原始数据集 ID |
| `Root` | `string` | 词根形式，如 `aud`、`port` |
| `Origin` | `string` | 语言来源，`Greek` 或 `Latin` |
| `Meaning` | `string` | 中文含义，如「听」 |
| `MeaningEn` | `string?` | 英文含义（可选） |
| `Description` | `string` | 词根详细说明 |
| `Examples` | `ICollection<WordRootExample>` | 关联示例词列表 |
| `Quizzes` | `ICollection<WordRootQuiz>` | 关联测验题列表 |

#### WordRootExample（词根示例词）

展示词根在实际单词中的应用。

| 字段 | 类型 | 说明 |
|------|------|------|
| `Word` | `string` | 完整单词，如 `audience` |
| `Prefix` | `string?` | 前缀部分 |
| `Root` | `string?` | 词根部分（高亮显示用） |
| `Suffix` | `string?` | 后缀部分 |
| `Meaning` | `string` | 单词含义 |
| `Explanation` | `string?` | 词义拆解说明 |

#### WordRootQuiz（词根测验题）

每个词根对应一道选择题，用于学习后即时巩固。

| 字段 | 类型 | 说明 |
|------|------|------|
| `Question` | `string` | 题目内容 |
| `OptionsJson` | `string` | 选项数组（JSON 存储） |
| `CorrectAnswer` | `int` | 正确答案索引（0-based） |

#### UserWordRootProgress（词根学习进度）

记录用户对每个词根的掌握状态。

| 字段 | 类型 | 说明 |
|------|------|------|
| `UserId` | `Guid` | 用户 ID |
| `WordRootId` | `Guid` | 词根 ID |
| `IsMastered` | `bool` | 是否已掌握 |
| `MasteredTime` | `DateTime?` | 掌握时间 |

### 3.2 个人单词本（SM-2 间隔重复）

#### UserWord（用户单词）

用户自由添加的单词，包含 SM-2 算法所需的全部状态字段。

| 字段 | 类型 | 说明 |
|------|------|------|
| `Word` | `string` | 单词 |
| `Definition` | `string?` | 释义 |
| `Example` | `string?` | 例句 |
| `RepetitionCount` | `int` | 已成功复习次数 |
| `EaseFactor` | `double` | 难度因子，初始 2.5，越低越难 |
| `Interval` | `int` | 当前复习间隔（天） |
| `NextReview` | `DateTime?` | 下次复习时间，`null` 表示从未复习 |

**SM-2 评分规则**：复习时传入 `quality`（0-5），≥3 为记住，<3 为遗忘并重置进度。间隔天数超过 21 天视为已掌握。

#### WordReviewLog（复习日志）

每次复习都会产生一条日志记录，用于统计。

| 字段 | 类型 | 说明 |
|------|------|------|
| `WordId` | `Guid` | 对应单词 ID |
| `Quality` | `int` | 本次复习评分（0-5） |
| `CreationTime` | `DateTime` | 复习时间 |

## 4. API 接口

> 所有接口通过请求头 `X-User-Id: <userId>` 传递用户身份，由网关注入，无需独立鉴权。

### 词根浏览

路由前缀：`/word-roots`

| 方法 | 路径 | 参数 | 说明 |
|------|------|------|------|
| `GET` | `/word-roots` | `page`、`pageSize`、`origin`、`search` | 获取词根列表（分页），支持按语源和关键词过滤 |
| `GET` | `/word-roots/{id}` | — | 获取词根详情，含示例词列表和测验题 |
| `GET` | `/word-roots/{id}/quiz` | — | 获取指定词根的测验题 |

### 词根学习进度

路由前缀：`/word-root-progress`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/word-root-progress` | 获取用户词根学习总进度（已掌握数、总数、已掌握 ID 列表） |
| `POST` | `/word-root-progress/{wordRootId}/master` | 将指定词根标记为已掌握 |
| `GET` | `/word-root-progress/next` | 获取下一个待学习词根的 ID（按 RootId 顺序） |

### 个人单词本

路由前缀：`/user-words`

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/user-words` | 获取单词列表（分页，支持关键词搜索） |
| `POST` | `/user-words` | 添加单词（同一用户不可重复添加相同单词） |
| `DELETE` | `/user-words/{id}` | 删除单词 |
| `GET` | `/user-words/due` | 获取今日待复习单词列表 |
| `GET` | `/user-words/random` | 随机获取未掌握单词（用于自由练习模式） |
| `POST` | `/user-words/{id}/review` | 提交复习结果，触发 SM-2 算法更新下次复习时间 |
| `GET` | `/user-words/stats` | 获取学习统计（总数、今日待复习数、已掌握数、复习次数） |
