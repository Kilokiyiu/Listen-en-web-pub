# EaseWord Android App

ListenEase 配套的 Android 单词本应用，基于 **Capacitor 8 + Vue 3** 构建。

> 📦 包名：`online.your-domain.wordbook`（示例；fork 后可改为 `your.company.yourapp`）
> 🎨 应用名：`EaseWord`
> 📱 平台：Android 6.0+（Capacitor 8 默认 minSdk=23）

> 💡 仓库当前默认包名为 `online.listenease.wordbook`，需修改为自有包名时同步改动：
> - `android/app/build.gradle`（`namespace` + `applicationId`）
> - `android/app/src/main/java/.../MainActivity.java`（包声明）
> - `android/app/src/main/res/values/strings.xml`（`package_name` / `custom_url_scheme`）
> - `capacitor.config.json`（`appId`）

---

## 功能概览

| 模块 | 说明 |
|------|------|
| 登录 | 与 ListenEase 网站账号体系互通，使用 JWT 认证 |
| 云端单词本 | 与 WordService API 同步，多设备共享 |
| 本地单词本 | 完全离线可用，基于 SM-2 间隔复习算法 |
| 应用内更新 | 启动时检查 `/downloads/version.json`，有新版本弹窗提醒 |
| 用户反馈 | 内置反馈入口，调用后端 SMTP/SendCloud 通道 |

> 云端与本地为两套独立数据，可随时切换。详见 [Front end/wordbook-app/README.md](../Front%20end/wordbook-app/README.md)。

## 快速开发

```bash
cd "Front end/wordbook-app"
npm install
npm run dev
```

开发时通过 Vite 代理到本地后端：
- `/api/identity` → `http://localhost:5263`
- `/api/word` → `http://localhost:5215`

## 打包 APK

详见 [BUILD_APK.md](../Front%20end/wordbook-app/BUILD_APK.md)。

```powershell
cd "Front end/wordbook-app"
npm install
.\scripts\build-apk.ps1
```

输出：`android/app/build/outputs/apk/debug/app-debug.apk`

## ⚠️ 安全注意事项

1. **签名密钥必须离线备份**：
   - `android/keystore.properties` 和 `android/wordbook-release.keystore` 已加入 `.gitignore`
   - **丢失后无法覆盖安装旧用户包**（应用签名必须一致）
   - 建议使用 1Password / 加密云盘 / 离线 U 盘多处备份

2. **不要提交**：
   - `android/local.properties`（含本机 SDK 路径）
   - 任何 `.jks` / `.keystore` 文件
   - `android/app/build/` 下的 APK/AAB

3. **生产环境 API**：
   - 通过 `.env` 中的 `VITE_API_BASE` 注入
   - 不要硬编码生产域名到源码（已统一改为占位符 `your-domain.com`）

## 应用内更新流程

1. 修改 `android/app/build.gradle` 的 `versionCode`（递增）和 `versionName`
2. 打包新 APK，命名为 `EaseWord-{version}.apk`
3. 上传到网站 `Front end/en-listen-user-ui/public/downloads/`
4. 更新 `version.json`：
   ```json
   {
     "versionName": "0.8.9.2",
     "versionCode": 11,
     "apkUrl": "https://your-domain.com/downloads/EaseWord-0.8.9.2.apk",
     "forceUpdate": false,
     "changelog": "..."
   }
   ```
5. 部署前端后用户启动 App 时自动检测并弹窗
